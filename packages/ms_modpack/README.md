# ms_modpack

Modpacks: the `minesync-pack.json` format, Modrinth API v2 client, `.mrpack`
import and export, the resolver, the install plan and the server installers
(`lib/io.dart`). Design: [docs/design/modpack.md](../../docs/design/modpack.md).

Test with `dart test` (fake transports only, no network).
