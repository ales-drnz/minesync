# minesync_cli

The `minesync` command line: `login`, `spaces`, `link`, `status`, `pull`,
`push`, `verify` and `play`, on the same engine as the desktop app and with
the same `config.json`. Commands: [docs/guide/app.md](../../docs/guide/app.md#the-cli).

Test with `dart test` (the `e2e` tag starts a real hub and the guard).
