# minesync_desktop

The MineSync desktop app (Flutter, Windows, macOS, Linux): connect to a hub,
play and host servers, history, mods and player pack, settings, tray and
self-update through `apps/launcher`. User guide:
[docs/guide/app.md](../../docs/guide/app.md).

Test with `flutter test` (TZ=UTC, headless); goldens are under
`test/goldens/`. Packages are built by `tools/package/desktop.sh`.
